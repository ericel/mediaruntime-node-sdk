## Validation

- Node SDK: 93 tests plus type/consumer checks; GitHub CI on Node 22 and 24; package/security checks passed.
- Python SDK: 66 tests plus Ruff, mypy, and wheel/sdist checks; GitHub CI on Python 3.10–3.14 passed.
- CLI: 78 tests, including real SDK serialization, local-file upload, omitted-default behavior, recipes, polling, and bundle download; Node 22/24 CI and package/security checks passed.
- Fresh installs from npm/PyPI verify versions and the opt-out request/response mapping independently of the source checkouts.
- Production smoke test: the published Node SDK uploaded a generated 16×16 PNG, submitted a billable `image.web` job with `deliverWebhook: false`, polled to `COMPLETED`, and downloaded an integrity-checked ZIP containing JSON and WebP outputs. Normal billing charged USD 0.02. The deployed Firestore record reported `webhookStatus: SKIPPED`, reason `job_webhook_delivery_disabled`, and zero attempts. No live account webhook settings were modified.

## Usage

```js
const job = await media.jobs.create({
  source: './product-video.mp4', outputs: ['video.web'], deliverWebhook: false,
});
const result = await job.wait();
```

```python
job = media.jobs.create(
    source='./product-video.mp4', outputs=['video.web'], deliver_webhook=False,
)
result = job.wait()
```

```bash
mediaruntime run ./product-video.mp4 --output video.web --no-webhook --download ./result.zip
```
