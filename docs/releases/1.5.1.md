# Node SDK 1.5.1 — 2026-11-09

This release combines the job-wait deadline fix with file-inspection support and
application policy checks.

## Job-wait deadlines

`media.jobs.wait()` and `Job.wait()` now apply `timeoutMs` to the entire local wait,
including requests, response-body reads, transport retry delays, and polling delays.
At expiration they reject with `JobWaitTimeoutError`, abort outstanding local work,
and preserve the last successfully decoded job observed before the deadline.
Late terminal responses cannot turn the timeout into success, and no further poll
or retry starts even when the deadline timer callback has not yet run.

Caller cancellation before expiration retains its reason. Concurrent waits remain
independent and release their timers and listeners on settlement. Standalone job
reads retain their transport timeout/retry behavior, and submissions retain their
idempotency behavior. A local timeout does not cancel the remote job.

## File inspection

- Add typed inspection quotes, job options, reports, cancellation, and sanitized
  derivative retrieval. Local inspection inputs use quarantined upload targets.
- Expose separate inspection quote/billing details and preserve bounded archive,
  image, and audio diagnostics, including incomplete and unsupported checks.
- Add `evaluateFileReport()` for backend application decisions based on format
  allowlists, scan freshness, complete evidence, ZIP entries, and derivatives.
- Refresh the checked-in public OpenAPI snapshot and provenance hash.

Inspection requires account enablement and a configured paid tariff. Enforcement
and sanitization have additional prerequisites described in the
[inspection guide](../SECURITY_INSPECTION.md). Publishing the SDK does not enable
these server features. A completed report may describe threats or incomplete
coverage; it is not an application acceptance decision or a guarantee of safety.

## Local validation

- `npm run check` passed.
- `npm test` passed: 241 tests passed, zero failed, and two optional image/audio
  fixture tests were skipped because their external report directories were not
  configured. This includes all 95 deterministic deadline regression cases.
- Against the pre-fix implementation, 67 of those deadline cases failed and 28
  passed, demonstrating the original behavior and preserved behavior.
- ESM/CommonJS exports, vendored contract hashes, and consumer type checks passed.
- `npm audit --audit-level=high` reported zero vulnerabilities.
- `npm pack --dry-run` passed, including its type-check and test hooks.

The optional fixture checks use `MEDIA_SECURITY_IMAGE_RUN` and
`MEDIA_SECURITY_AUDIO_RUN`. These local results do not establish live inspection
service behavior or registry publication. Follow the [release process](../RELEASING.md)
for GitHub CI, tag-triggered publishing, and clean registry installation checks.
